# Раздельная загрузка каталога и отчёта — 15.11.2026

## Страница SentisSite

- Начальная страница запрашивает только `/api/battles?hours=24&page=1`: максимум 50 компактных карточек с ID, названием, временем, боевым уроном и поисковыми именами/фракциями.
- Результат сторон, участники со статистикой, MVP, экономика, таймлайн, прыжки и разбивка приходят только через `/api/battles/<id>`.
- Первый бой больше не выбирается автоматически. Без `?battle=...` остаётся приглашение выбрать сражение.
- Прямая ссылка загружает только свой отчёт, после получения каталога, но не удерживает кнопки списка disabled в ожидании подробностей.
- Обновление списка и подгрузка следующей страницы не перезапрашивают выбранный отчёт. Выбор другой карточки отменяет предыдущий запрос подробностей; прежний ограниченный кэш отчётов сохранён.
- Карты и кнопки экспорта на публичной странице нет. Backend API остаётся read-only источником данных страницы.

## Watcher

Раньше первый запрос каталога за 24 часа всегда читал полные 168 часов. Теперь общий минутный снимок начинается с подходящего окна 24/72/168 часов. Запрошенный фильтр применяется точно; округление окна вверх ограничивает число возможных расширений кэша тремя, а не допускает отдельную тяжёлую выборку для каждого значения hours.

Если прямая ссылка отсутствует в узком снимке, проверка членства расширяется до допустимых 168 часов. Неверный ID не запускает сборку подробного отчёта. Прежние проверки Bearer/loopback, задержки, завершённости, возраста и ограничение одновременной работы сохранены.

В чтении списка не загружаются приватные ключи связи экономики и метки телеметрии/атрибуции, не выбираются имена гридов. Статистика выстрелов, экономика и таймлайн и раньше рассчитывались только для выбранного отчёта.

Дополнительно исправлен дорогой поиск связанных событий: активность боя хранится хронологически, включая слияние цепочек. Двоичный поиск ограничивает проверку временным окном ±120 секунд, а не перебирает всю историю многочасового боя для каждого события. Правила радиуса, связности, временных границ и неоднозначного контекста не изменены.
